# Hack-Club-weather-station
This projects consits on a weather station that me and my friends will build for the hack club fallen program where we hope to qualify for shenzen
This weather station will be able to determine the wind speed and wind direction, rain accumulation, pressure and temperature all of the results will be tracked by a wifi app that will conect to the weather station
How do we plan on building it?
First of all we will CAD design the anemometer and the main body of the station, we will design some custom PCB's we will also create an assembly guide, While we are doing this a member of the group will be encharge of the programing of the app and the hardware.
